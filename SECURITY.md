# Security

Found a security problem in SAR Duty? Email <support@sarduty.com>. Say what you found
and how to reproduce it. We'll reply, fix it, and tell you when it's fixed.

Please don't open a public issue for it. Email is the one way to report, so GitHub's
private vulnerability reporting is off.

The same contact is at
[sarduty.com/.well-known/security.txt](https://sarduty.com/.well-known/security.txt).
